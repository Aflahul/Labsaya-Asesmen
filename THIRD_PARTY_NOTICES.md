# Dependensi dan aset

Phaser 3: MIT, https://github.com/phaserjs/phaser/blob/master/LICENSE.md.
Vite, Fastify, node-postgres: MIT; teks lisensi terdapat pada paket masing-masing dan lockfile mematok versi distribusi. Vitest, Playwright, PGlite, pg-mem dan Prettier dipakai untuk pengembangan/pengujian, bukan aset runtime frontend.

Ilustrasi dibuat secara programatik dari bentuk geometris lokal. Audio dihasilkan melalui Web Audio. Font memakai font sistem; aplikasi tidak mengunduh font/aset eksternal.
